## 1. 项目定位

CareerOS 是面向求职者的个人求职 CRM 与知识管理系统，集中管理任务、岗位、知识卡、资料和随手记，并通过可替换的大模型 API 提供结构化整理能力。

项目采用“一套代码、两个独立部署环境”：

```text
GitHub 代码仓库
├── 私人环境 → 私人 D1 + 私人 R2 → 保存项目所有者真实数据
└── 公开环境 → 公开 D1 + 公开 R2 → 每位用户获得独立空白工作台
```

- 私人环境与公开环境绝不共用数据库和文件存储。
- GitHub 只保存代码、迁移和文档，不保存私人数据或 API 密钥。
- 当前先完成可使用、可演示的 MVP，再进行数据库拆表、知识库和自动化升级。

### 当前登录方案说明

当前没有开发 CareerOS 自有的账号密码、微信登录和页面内退出功能。MVP 使用托管平台传入的登录身份，后端根据该身份生成稳定的用户编号并隔离数据。

账号密码、微信登录、找回密码和账号绑定属于升级版，不阻塞当前私人使用及作品展示。

# 第一阶段：MVP

## 5. MVP 验收目标

MVP 需要满足：

1. 私人数据和文件能够持续保存。
2. 未登录请求不能读取业务数据。
3. 每个登录用户只能读取、修改和删除自己的数据与文件。
4. 六个核心模块能够完成主要操作。
5. 桌面端和移动端核心流程可用。
6. AI 未配置或调用失败时不破坏原始数据。
7. GitHub 不包含密钥、Token、私人数据和构建文件。
8. 公开环境使用独立的空白 D1、R2。
9. 面试官可以通过公开网址体验项目。
