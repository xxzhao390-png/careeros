# 安全说明

## 已实现

- 服务端从可信登录身份获取用户，不信任客户端提交的用户编号。
- 业务查询、修改和删除同时校验记录编号与用户编号。
- 文件使用用户目录前缀，并在 D1 中校验文件所有权。
- 文件大小限制为 15MB。
- AI Key 仅通过环境变量读取。
- AI 输入限制长度，输出经过字段与长度校验。
- AI 调用有每日额度和失败记录。

## 上线前必须验证

- 用户 A 无法读取、修改或删除用户 B 的记录。
- 用户 A 无法访问用户 B 的 R2 文件。
- 新用户看到空白工作台。
- Git 历史不包含密钥、Token 或真实个人数据。
- 公开部署使用独立的 D1 和 R2。

## 暂不支持

- 微信登录
- 忘记密码和邮件重置
- 管理员后台
- 高级风控与验证码

这些能力不阻塞当前个人作品集 MVP，进入公开规模化使用前应继续补充。
