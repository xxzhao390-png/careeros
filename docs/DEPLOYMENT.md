# 部署说明

## 1. 部署目标

CareerOS 使用一套源代码和两个独立部署：

| 环境 | 数据库 | 文件存储 | 数据内容 |
|---|---|---|---|
| 私人版 | 私人 D1 | 私人 R2 | 项目所有者真实数据 |
| 公开版 | 公开 D1 | 公开 R2 | 新用户各自的空白数据 |

## 2. GitHub 中保存什么

GitHub 保存源代码、SQL 迁移、测试和文档，不保存线上 D1 数据、R2 文件、API Key、Cookie、Token 或真实求职资料。

## 3. 发布流程

1. 安装依赖并执行构建与测试。
2. 检查 SQL 迁移文件。
3. 私人部署绑定私人 D1 与 R2。
4. 公开部署绑定全新的 D1 与 R2。
5. 分别应用相同数据库迁移。
6. 使用两个普通账号测试数据与文件隔离。
7. 只把公开部署链接放入简历。

## 4. AI 可选配置

不配置 AI 环境变量时，网站的数据库与文件功能仍可运行。启用 AI 时，在部署环境配置 `AI_API_KEY`、`AI_BASE_URL` 和 `AI_MODEL`，不要写入代码仓库。

## 5. 发布后迭代

代码更新后重新构建和发布即可。数据库结构变化必须新增迁移文件，不能直接修改已经执行过的旧迁移。
